Sistema backend desenvolvido com Java e Spring Boot para gerenciamento de filas hospitalares para uma melhor separação por exames ou departamentos
avisando ao pacientes pelo WhatsApp que Seu Exame já está marcado.
## Funcionalidades

- Cadastro de pacientes
- Sistema de prioridade
- Controle de fila
- Integração com WhatsApp
- Envio automático de mensagens para pacientes
- API REST
- Persistência com MySQL
