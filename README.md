# 🏥 Fila API — Sistema de Gerenciamento de Filas Hospitalares

## 📌 Sobre o Projeto
 
O **Fila API** é um sistema backend para hospitais e clínicas que precisam organizar e controlar filas de atendimento de forma eficiente. O sistema permite cadastrar pacientes, definir prioridades de atendimento e notificar automaticamente cada paciente via WhatsApp quando seu exame ou consulta está confirmado.
 
---

## ✅ Funcionalidades
 
- 👤 **Cadastro de pacientes** — Registro completo com dados pessoais e de contato
- 🚨 **Sistema de prioridade** — Classificação por urgência e tipo de atendimento
- 🗂️ **Controle de fila** — Organização por departamentos e tipos de exame
- 📱 **Integração com WhatsApp** — Notificações automáticas ao paciente
- ✉️ **Envio automático de mensagens** — Aviso quando o exame é marcado
- 🔌 **API REST** — Endpoints padronizados e documentados
- 🗄️ **Persistência com MySQL** — Banco de dados relacional robusto
